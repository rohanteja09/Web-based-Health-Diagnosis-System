![TiDB Cloud](https://img.shields.io/badge/Database-TiDB%20Cloud-green)# 🏥 Web-Based Health Diagnosis System

A **Java-based Web Health Diagnosis System** designed to assist healthcare professionals by analyzing historical patient records and supporting disease diagnosis through machine learning techniques. The application provides an intuitive web interface for managing medical datasets, preprocessing data, performing disease analysis, and evaluating prediction models.

The project is built using **Java (JSP & Servlets)**, **Apache Tomcat**, **Maven**, **MySQL/TiDB Cloud**, and is deployed using **Docker** on **Render**.

---

## 📌 Project Overview

The Web-Based Health Diagnosis System is a healthcare analytics platform that utilizes historical patient records to support disease prediction and diagnosis. The system allows administrators to upload medical datasets, preprocess patient records, analyze diagnosis information, and evaluate machine learning models through a web-based interface.

The application simplifies healthcare data management while providing an efficient environment for analyzing medical datasets and improving disease diagnosis workflows.

---

## 🎯 Objectives

- Develop a web-based platform for healthcare data management.
- Store and manage historical patient health records.
- Preprocess medical datasets before analysis.
- Perform disease prediction using machine learning techniques.
- Analyze prediction performance using evaluation metrics.
- Deploy the application on a cloud platform for easy accessibility.

## 🔄 Project Workflow

1. Administrator logs into the system.
2. Medical datasets are uploaded.
3. Patient records are stored in the database.
4. Data preprocessing removes inconsistencies.
5. Machine learning algorithms analyze historical records.
6. Disease prediction is performed.
7. Results and performance analysis are displayed.
